# PWB DKP

Public standings and history generated from the guild's approved private CappedDKP ledger.

The page uses the guild's supplied logo, Horde-inspired styling, guild application and progress links,
and a public Armory snapshot of 73 character names with profile links, captured on 2026-11-15.
The roster is not a live feed and does not establish DKP eligibility.

**Ledger setup pending:** no approved DKP balances or loot records have been published.

After setup, approved ledger updates replace `index.html`, `standings.json` and `history.json`.
This repository must never receive the private journal, SavedVariables, Discord identities,
BattleTags, officer notes, disciplinary records, API keys or webhook URLs.

GitHub Pages serves the root of `main`. The page is a read-only copy, not the authoritative ledger.
